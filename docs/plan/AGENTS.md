# 计划文档目录协作规则

## 范围与用途

- 本目录保存 LumenDesk 的阶段性实施计划和可执行待办，不保存抓取原文、个人数据、密钥或运行日志。
- `plan.md` 是目标、边界、里程碑、风险和验收口径的单一事实源；`todo.md` 是按周执行的任务清单。

## 编辑边界

- 计划必须区分外部来源事实、LumenDesk 自有政策、未审核草案和已生效知识。
- 未经用户确认产品、来源授权和公开范围，不在本目录记录具体网页抓取结果，也不把第三方政策表述为 LumenDesk 官方政策。
- 计划变更要同步更新 `plan.md` 与 `todo.md`，避免只改其中一个文件。

## 运行与验证

- 文档修改后检查 Markdown 结构、任务编号、依赖关系和验收条件。
- 提交前运行 `git diff --check`，并确认没有加入 `.env`、抓取快照或生成物。

## 维护口径

- 每周复盘只保留仍然有效的任务和假设；过期方案标记为废弃，不静默删除历史决策。
